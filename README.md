# RedRock Email Classifier

Classifies inbound RedRock client emails into one of five business categories
— Account Management, Investment Advisory, Loan Processing, Insurance Claims,
Other — so they can be routed to the correct department. Outputs a predicted
category and a confidence score per email.

See [UoW.md](UoW.md) for the full unit-of-work write-up: approach comparison,
evaluation results, calibration findings, and regulatory considerations.

## Setup

Requires Python 3.10+.

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

The embedding classifier downloads a small (~90MB) sentence-encoder model
(`sentence-transformers/all-MiniLM-L6-v2`) from Hugging Face on first run;
this requires internet access once, then works offline.

## Running it

Everything — data loading, cross-validation, and final test-set predictions
— runs end to end with one command:

```bash
python src/evaluate.py
```

This will:
1. Load the 44 labeled training emails and the 12 unlabeled test emails from `data/`.
2. Run 5-fold stratified cross-validation for both classifiers on the training set.
3. Fit each classifier on all 44 labeled emails and predict the 12 test emails.
4. Write, into `results/`:
   - `predictions_baseline_tfidf_logreg.csv`
   - `predictions_embedding_centroid.csv` — **this is the primary submission**
   - `evaluation_results.json` (full metrics, per-class breakdown, calibration table)
   - `comparison.csv` (headline comparison table)

Each predictions CSV has the columns required by the spec: `email_id,
predicted_category, confidence_score`.

## Running the tests

```bash
python -m pytest tests/ -v
```

## Project layout

```
src/
  ingestion.py            parses the HTML emails into structured records
  classifier_baseline.py  TF-IDF + Logistic Regression
  classifier_embedding.py sentence-embedding nearest-centroid classifier (primary)
  evaluate.py             cross-validation + final predictions, single entry point
data/
  train/, test/, train_labels.csv   provided sample data
tests/                     pytest suite for ingestion, both classifiers, and eval harness
results/                   generated by evaluate.py (not committed pre-run)
```
